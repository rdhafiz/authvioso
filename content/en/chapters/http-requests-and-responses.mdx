## Requests and responses

Every exchange on the web is a request and a response. The request says what
you want and carries some context about who is asking; the response says what
happened and carries some instructions about what to do next.

Almost everything in this curriculum is about that second part — specifically,
about which pieces of context a request carries, where the browser got them,
and who else could have got them too.

### Headers worth knowing early

| Header          | Direction | Carries                                    |
| --------------- | --------- | ------------------------------------------ |
| `Cookie`        | Request   | State the browser was told to send back    |
| `Set-Cookie`    | Response  | State the server wants stored              |
| `Authorization` | Request   | Credentials the client attached on purpose |
| `Origin`        | Request   | Where the request was initiated from       |

The distinction in that last column matters more than it looks. The browser
attaches `Cookie` on its own, without the page asking. `Authorization` only
appears because some code put it there. That single difference is the reason
cross-site request forgery exists for one and not the other.

## Reading a response

```http
HTTP/1.1 200 OK
Content-Type: text/html; charset=utf-8
Set-Cookie: session=abc123; HttpOnly; Secure; SameSite=Lax
```

Three attributes on that cookie, each defending something different. Pulling
any one of them out breaks a different thing, which is why they get a chapter
of their own later.

<Callout variant="security" title="What this doesn't cover">
  A response arriving intact tells you nothing about who sent the request.
  Transport security and identity are separate problems, and conflating them is
  one of the more expensive mistakes in this subject.
</Callout>

## Status codes

- `401` means the server doesn't know who you are.
- `403` means it knows and you still can't.

They get used interchangeably in the wild and it causes real confusion — a
client that retries on `403` will loop forever.
