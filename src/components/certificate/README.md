# certificate

Status, the issuance form, and the public verification view.

The form asks for a name and a way to reach the person. That's it — no
employer, no job title, no country, no optional extras. This is the only point
in the entire site where we ask who someone is, and the reason for asking is
shown before the form, not after.

Verification returns four things: name, curriculum version, issue date, and
whether the signature is valid. Not scores, not attempt counts, not progress,
not their email. Someone gave us a name for a certificate; anything beyond
that is a leak.

Unknown ID gets a flat "not found". Don't hint that it nearly matched.

Also worth stating up front, before someone asks for it later: no share
buttons, no badges, no "add to profile" integrations.
